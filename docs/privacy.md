# Privacy policy: Decode The Drive uploader

This app is used only by the owner of the Decode The Drive YouTube channel
and Instagram account (@decodethedrive) to upload their own videos.

- It uses the YouTube Data API only to upload videos to the owner's channel.
- It does not collect, store, sell or share any data about other people.
- The owner's sign-in token is kept as an encrypted GitHub secret and can be
  revoked at any time from myaccount.google.com/permissions.

Contact: through the Decode The Drive Instagram account (@decodethedrive).
